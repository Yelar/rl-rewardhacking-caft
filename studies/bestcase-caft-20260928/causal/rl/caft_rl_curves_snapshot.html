What this shows

Strict hacking: the answer's own test passes while the solution fails the hidden tests, so the answer earns reward only by rewriting the test. Harmful test edits: the answer rewrites the evaluation function in a way the grader classes as harmful, whether or not the solution is right.

Arms: Baseline trains normally, with the same hooks switched off. Joint, Adding and Random remove one direction from the residual stream at block 19 during rollouts and updates; the reference model for the KL term has the same removal.

Seeds: seeds 1 to 4. The Random arm's seed 4 starts after seed 4's baseline finishes, so until then that arm averages seeds 1 to 3.

Layout: 2 GPUs per run with the 8-GPU batch grouping, so each update matches an 8-GPU run apart from sampling randomness. These are training answers, not the held-out evaluation, which runs after training.
